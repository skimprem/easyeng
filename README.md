# EasyEng

Веб-приложение для чтения текстов на иностранном языке: двойной клик по незнакомому
слову — и перевод появляется прямо над ним.

## Возможности

- **Читалка**: перевод слова по двойному клику, фразы — через выделение и кнопку «Перевести».
  На телефоне — тап по слову; текст там невыделяемый, чтобы не всплывали меню Chrome
  («Перевести / Скопировать», Touch to Search). Для фразы — кнопка ⇔ включает выделение.
  Перевод можно закрепить над словом: клик по любому из вариантов (или клавиши `1`–`9`),
  📌 / `P` — первый вариант; клик по закреплённому переводу — убрать.
  Закреплённые переводы автосохраняются на сервере и переживают правку текста;
  кнопка ⟲ в панели читалки сбрасывает их все (с подтверждением).
  Размер шрифта, темы (светлая / сепия / тёмная), запоминание места чтения.
- **Языки**: пара «с какого → на какой» задаётся в настройках и меняется прямо в читалке.
  Поиск находит словарную форму: *went → go*, *children's → child* (лемматизация simplemma).
- **Словари** — цепочка провайдеров, опрашиваются по порядку:
  - локальные (StarDict / FreeDict / TSV), работают без интернета;
  - MyMemory — бесплатный онлайн-перевод без ключа;
  - Wiktionary — толкования на языке оригинала;
  - LibreTranslate — открытый self-hosted перевод (включается переменной `LIBRETRANSLATE_URL`).
- **Личный словарик** с карточками для заучивания. Слова попадают туда из читалки — кнопкой ☆ (`S`)
  или автоматически при закреплении перевода; сохраняется словарная форма (*went → go*),
  перевод и предложение из текста.
  Повторение — по коробкам Лейтнера: свайп **вправо** («знаю») переносит слово в следующую коробку,
  интервал растёт 1 → 3 → 7 → 21 → 60 дней (выученное всё равно изредка возвращается);
  свайп **влево** («не знаю») — слово возвращается в эту же сессию и уходит на заучивание.
  Против угадывания: ответить можно только открыв карточку; в сессию подмешиваются
  внеплановые проверки знакомых слов; есть режимы «перевод → слово» (с пропуском в контексте)
  и «вперемешку». Клавиши: пробел — открыть, ← / → — ответ, `V` — произношение.
- **Библиотека**: загрузка `.txt` / `.md`, поиск и импорт книг из Project Gutenberg,
  редактор Markdown с живым предпросмотром, обмен текстами между пользователями.

## Запуск в Docker (PostgreSQL)

```bash
cp .env.example .env        # заполнить DJANGO_SECRET_KEY и POSTGRES_PASSWORD
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
docker compose exec web python manage.py install_freedict eng-rus
```

Открыть http://localhost:8000. Данные — в томах `pgdata` (база) и `appdata` (кэш, загрузки).
Миграции применяются автоматически при старте контейнера.

## Запуск для разработки (SQLite)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py createsuperuser
.venv/bin/python manage.py install_freedict eng-rus   # открытый словарь en→ru, ~62 тыс. слов
.venv/bin/python manage.py runserver
```

Открыть http://127.0.0.1:8000. База, кэш и загрузки лежат в `var/`.

Тесты: `.venv/bin/python manage.py test`

## Словари

```bash
manage.py install_freedict                 # каталог FreeDict для поддерживаемых языков
manage.py install_freedict eng-rus deu-rus # установить как общие словари
manage.py import_dictionary file.zip --src en --tgt ru [--user имя] [--name "Название"]
```

Порядок опроса словарей каждый пользователь задаёт в настройках перетаскиванием (или кнопками ↑↓).
Пользователи могут загружать личные словари через раздел «Словари»;
администратор — ставить общие из каталога FreeDict прямо из интерфейса.

Форматы:
- **StarDict** (`.ifo` + `.idx[.gz]` + `.dict[.dz]`, можно архивом `.zip` / `.tar.*`) — формат FreeDict и
  большинства открытых словарей;
- **TSV**: `слово<TAB>перевод1; перевод2`, строки с `#` — комментарии.

Новый формат: модуль в `dictionary/importers/` с функцией `parse(directory) -> (info, entries)`
и строка в `detect_format()`.

Новый онлайн-словарь: класс-наследник `Provider` / `OnlineProvider` в `dictionary/providers/`
с методом `lookup()` и строка в `PROVIDER_CLASSES` в `registry.py`.

## Устройство

| Приложение   | Что внутри |
|--------------|------------|
| `accounts`   | регистрация, профиль (языки, выбранные словари) |
| `library`    | тексты, Markdown, импорт Gutenberg (`sources/`), обмен текстами |
| `dictionary` | модели словарей, провайдеры, импорт, API `/dictionaries/lookup/` |
| `vocab`      | личный словарик, карточки, расписание повторений (`models.Card.answer`) |

Фронтенд — шаблоны Django + небольшой ванильный JS (`static/js/`), без сборки.
Весь HTML из внешних источников и Markdown пользователей проходит санитизацию (nh3).

## Переменные окружения

`DJANGO_SECRET_KEY` (обязателен при `DJANGO_DEBUG=0`), `DJANGO_DEBUG` (0/1), `DJANGO_ALLOWED_HOSTS`,
`DJANGO_CSRF_TRUSTED_ORIGINS`, `DJANGO_SECURE_COOKIES` (1 — за HTTPS), `DATABASE_URL`
(`postgres://user:pass@host:5432/db`; без неё — SQLite), `EASYENG_VAR_DIR`, `DJANGO_STATIC_ROOT`,
`MYMEMORY_EMAIL` (увеличивает дневную квоту MyMemory до 50 000 слов),
`LIBRETRANSLATE_URL`, `LIBRETRANSLATE_KEY`.
